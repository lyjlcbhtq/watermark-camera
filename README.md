# 简单水印相机

面向代驾接车前、交车后车况留证的网页版水印相机，支持添加到 iPhone 主屏幕。生产环境需要 HTTPS，开发时可使用 localhost。当前版本：1.5.0。

访问入口：**https://lyjlcbhtq.github.io/watermark-camera/** 。用 iPhone 的 Safari 打开，允许相机与定位权限；需要录音时允许麦克风。点击 Safari 的“分享 → 添加到主屏幕”即可像应用一样进入，无需苹果开发者账号或 App Store 安装。使用流程见 [使用说明.md](使用说明.md)。

当前仓库沿用 GitHub Pages 的 `main` 分支根目录发布，保留根目录 `.nojekyll`，以免校验组件中以 `_` 开头的文件被排除。Pages 只提供静态页面，不能运行地址代理；当前入口可使用设备坐标，但没有中文地图地址服务。GitHub Pages 免费托管不代表国内网络始终可达。

## 1.5.0 车况录像与文件核对

- **录像优先**：默认进入录像，保留省电 720p 与可选 1080p。Safari 编码格式不支持时尝试兼容格式；录像中持续显示麦克风状态。支持的浏览器会请求保持亮屏，停止或后台时释放；不保证系统永不锁屏。
- **对应本次车辆**：选择接车前／交车后，选填车牌或车辆标记与订单尾号。字段进入水印和采集记录，录像中锁定设置；“新一单”清空标记，刷新页面也会清空，避免沿用上一单。
- **定位精度可见**：使用最长 12 秒的高精度采样窗口，优先保留较好的新鲜位置，显示浏览器报告的估计误差、WGS84 坐标与采样时间。精度未知、定位失败、超过 30 秒未更新均明确标注；不会把附近店名当成准确位置。录像中最多每 45 秒发起一次短时更新，后台停止采样。
- **采集记录**：保存设备开始/结束时间、单调时钟测得的时长、车辆/订单字段、定位样本、音频中断和录制异常；检测明显设备时钟跳变。地图地址是估算，手填地址和选定地点明确标记未核验。
- **原文件与校验记录**：优先下载应用生成的水印成片，随后点击“导出校验记录”，计算完成后再点“下载校验记录”。SHA-256 在 Worker 中按 2 MiB 分块计算，不上传视频。`verify.html` 可选择视频与 JSON 进行核对；旧作品仍可计算文件校验值，但不补造当时的采集信息。
- **国内访问准备**：首屏不依赖外部字体、图标库或地图脚本；定位和地址查询不阻塞相机启动。新增同源地址代理与国内 HTTPS 部署模板，高德 Key 留在服务端。未配置服务端地址服务时仍显示设备坐标，已安装的页面与校验组件可离线加载。

**这不是滴滴官方取证工具，也没有第三方存证或可信时间戳认证。** 浏览器时间、位置、手填信息以及 JSON 都可能被修改；文件与本机记录匹配只说明两者一致，不能证明拍摄信息真实或保证被平台、法院采信。本应用保存的是浏览器合成的水印成片，不是未经处理的摄像头原始码流。

建议流程：接车前先记录车牌和整车，再连续绕拍车身四角、轮毂与已有损伤；既拍损伤细节，也拍它在车身上的位置。交车后按同样顺序复拍。核对声音和可播放性后，将原文件与 JSON 一起另存，避免只保留聊天软件压缩副本。重要材料可以另交受理方认可的平台保存，具体要求以对方实际规则为准。

国内上线与地址服务配置见 [deploy/README.md](deploy/README.md)。当前未配置国内自有域名/服务器/高德 Key，未完成国内移动、联通、电信实网测速，也未接入滴滴或第三方存证。

## 1.4.0 界面重设计

- **统一视觉**：暖白色设置与相册、柔和绿色选中态、统一的内嵌 SVG 线性图标；无需下载图标库或外部字体。
- **取景布局**：深色取景底，顶部显示当前画质，拍照/录像切换放在快门上方；相册和水印按钮增加文字。横屏采用右侧拍摄操作栏，取景与水印避开控件。
- **设置面板**：画质、内容、地点与样式分组显示；输入框独占一行，完成按钮随面板滚动保持可见。保留键盘焦点与读屏状态。
- **相册与成片**：更清晰的缩略图网格、空相册提示和本机存储说明；成片预览突出保存操作，分享、下载和删除分别呈现，横屏将操作放在右侧。
- **性能保留**：保留 720p 默认画质、相机释放和相册分页。界面不使用实时背景模糊，录像指示使用静态状态，系统开启减少动态效果时停用过渡动画。

界面已检查 320×568、390×844、844×390 三种尺寸。截图中的模拟画面用于布局验证，不代表真实摄像头画质。

## 第三轮改进

- **可选画质**：默认「省电 720p」，可在设置里切换「清晰 1080p」，并记住选择。切换时先释放旧摄像头；拍摄和保存期间禁止切换。实际分辨率由设备能力决定，高清会增加耗电和文件大小。
- **取景与成片一致**：取景保留完整画面，水印预览与照片、录像共用同一套排版。横竖屏时避开操作栏，小屏模式按钮保持单行，录像计时器不再覆盖按钮。
- **减少无效绘制**：水印内容没变化时复用预览画布；隐藏时间后不再逐秒重画静态水印。录像按媒体时间控制帧率，避免浏览器回调抖动造成额外丢帧。
- **旋转与后台行为**：录像开始后保持输出尺寸，旋转时按比例容纳画面，避免拉伸；切后台同时暂停作品播放。相机释放时清空预览画布。
- **相册分页**：每次读取 30 条作品信息与缩略图，按需加载更多；读取失败可重试。数据库升级只新增排序索引，保留已有照片和视频。
- **操作与辅助功能**：开关、选项和拍摄按钮提供名称及状态；面板增加明确关闭按钮，支持键盘焦点循环和返回入口；启用附近地点时自动选择最近结果。

## 第二轮修复

- **作品持久保存与内存释放**：照片/视频存入 IndexedDB，列表只读取元数据与小缩略图，打开预览才读取完整媒体。关闭预览、相册时释放对象 URL。作品可在预览中删除。
- **存储失败保护**：事务真正提交后才显示保存成功。打开数据库或操作超时会失败并允许重试；容量不足时保留临时副本并明确提示另存。临时作品累计达到 96 MiB 后暂停新拍摄，不自动删除作品。
- **保存与删除竞态**：拍照或录像保存过程中锁住相关操作，避免迟到写入让已删除作品重新出现；关闭预览后，迟到的数据库读取不再重开窗口。
- **录像异常恢复**：每段独立会话，旧事件不能破坏下一段录像。停止后 5 秒仍无最终事件会释放资源，尝试保留已收到的片段；短暂视频静音允许 1.5 秒恢复，持续中断提供重试。
- **录像内存上限**：每段最长 3 分钟，或收到的编码数据达到 64 MiB 时结束。最终文件可能略大于容量阈值。异常中断保留的片段需要检查是否可播放。
- **照片编码异常**：编码超过 15 秒可恢复重试，迟到回调不再干扰后续拍摄。图像截取后立即关闭相机，不在写入存储时继续采集。当前省电模式照片长边最高 1280，清晰模式最高 1920。
- **定位恢复与正确性**：定位中切后台或后台首次启动后，返回前台会重新发起定位；旧回调被丢弃，定位失败不再继续打印旧地点。国外坐标不使用 GCJ-02 偏移。附近地点使用纯文本渲染。
- **水印与分享**：设置按部署路径保存在本机；长地址和自定义文字按字宽换行，必要时缩小字体，避免成片截字。分享只发起一次，失败后由用户点击下载重试；下载开始不再误报已保存到系统相册。
- **离线更新**：每个部署路径独立缓存，完整下载新版后等待旧窗口关闭再启用；失败更新保留工作版本，其他应用的缓存不受清理影响。

## 第一轮优化保留

默认请求 1280×720、最高 24 帧的预览，仅录像时申请麦克风。查看成片、相册、离开页面或进入后台时释放相机。录像按视频帧绘制，水印内容未变化时复用画布。麦克风不可用时允许无声录像；相机权限拒绝、启动超时和中断均有重试入口。

## 运行和部署

无需构建。Node.js 22+ 可直接运行同源服务：

```sh
npm start
```

默认访问 `http://127.0.0.1:8080/`。需要静态托管时，先导出公开资源：

```sh
node deploy/export-public.mjs /tmp/watermark-camera-public
```

该目录包含以下必需资源，部署时保持目录结构：

- `index.html`
- `media-store.js`
- `location-service.js`
- `evidence.js`、`evidence-worker.js`
- `verify.html`、`verify.js`
- `vendor/noble-hashes/` 中的运行脚本及许可证
- `sw.js`
- `manifest.json`
- `icon.svg`
- `icons/`

支持 `/watermark-camera/` 子路径。纯静态托管也可拍摄和核对文件，中文地址查询需要另配同源 API；它不是选择托管方式后就会自动可用的功能。

首次加载、安装缓存以及下载更新需要联网。每次修改页面或应用资源时，递增 `sw.js` 内缓存版本号。新版本缓存完成后，关闭该站点**全部浏览器标签和主屏幕应用窗口**，再打开以启用更新。没有强制刷新正在拍摄的页面。

## 自动化验证

```sh
npm ci
npx playwright install chromium
npm test
```

测试使用 Chromium 模拟媒体设备、真实 IndexedDB 和 Worker，以及 Service Worker 行为模型，覆盖拍摄、资源释放、存储与相册、离线更新、定位采样与精度、设备时间跳变、校验记录导出与核对、地址代理密钥隔离/限流/超时，以及横竖屏和键盘操作。

可选 WebKit 检查（需要系统依赖）：

```sh
npx playwright install --with-deps webkit
TEST_WEBKIT=1 npm test
```

当前云端缺少 WebKit 系统依赖，默认会明确跳过 WebKit 检查。模拟设备及桌面 WebKit 都不能代替 iPhone 真机的功耗、摄像头中断和系统分享验证。

## 使用限制与真机验收

- 本机作品由浏览器存储管理，清除网站数据或系统回收可能导致丢失；重要作品请下载原文件和校验记录到“文件”等独立位置。未落盘的临时作品会在刷新或关闭页面后丢失，预览内有明确提示。
- 单段录像最长 3 分钟，不支持后台持续录像；锁屏或切应用会结束当前片段。浏览器或系统强制终止页面可能来不及完成最后一次写入。
- 默认画质以省电为优先。保留完整画面时取景区域可能出现留边，小屏幕上水印看起来较小，可在设置中调整字号。1080p 不保证所有设备都能达到。
- 页面可以离线启动，但地址查询需要网络；iOS 清理站点缓存后需要重新联网加载。

真机验收建议：连续预览 10 分钟比较发热；连续拍照并刷新后检查相册；多次录像、播放和保存；锁屏/切应用后恢复；拒绝麦克风后测试无声录像；成功安装缓存后飞行模式重开。

本版本尚未在 iPhone 真机测量功耗；网页发布成功也不能代替真机验收。
